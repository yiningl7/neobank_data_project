# Neobank Customer Churn Prediction & Analysis

## Overview
This project analyses customer data for a digital bank to identify key factors influencing churn and builds a predictive machine learning model to anticipate customer churn.

## Features & Files
* `neo_bank.ipynb`: Exploratory data analysis, feature engineering, and model training.
* `churn_model.pkl`: Saved machine learning model for churn prediction.
* `app.py`: Streamlit web application interface for interactive predictions.
* `requirements.txt`: List of Python libraries required to run the project.

## Setup Instructions
1. Clone the repository:
   git clone https://github.com/yiningl7/neobank_data_project.git

2. Install dependencies:
   pip install -r requirements.txt

3. Run the application:
   streamlit run app.py
